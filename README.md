# my-market-app
Веб-приложение «Витрина интернет-магазина» с использованием Spring Boot.

## Описание проекта
Веб-приложение представляет собой витрину товаров, которые пользователь может положить в корзину и купить.
Приложение состоит из шести основных частей (модулей): страницы витрины товаров, доступных для просмотра и покупки; страницы товара; страницы корзины покупателя; страницы всех заказов; страницы заказа; сервиса покупки (не имеет отдельной веб-страницы).
Страница витрины товаров — это веб-страница (html + javascript), на которой представлены:
список товаров, доступных для заказа (картинка, название, описание, цена, кнопка добавления в корзину/удаления из неё, кнопка изменения количества товара в корзине);
список товаров может быть представлен в любом виде (списком, плиткой);
есть пагинация (по 2, 5, 10, 20, 50, 100 товаров);
сверху строка поиска с фильтрацией по названию (можно просто по вхождению слова в название/описание товара);
сверху доступна сортировка по цене, алфавиту.

### Требования к окружению
- **Java 21**
- **MySql**

### Как собрать и запустить в среде разработки
#### 1. Установка зависимостей.
Соберите проект с помощью Maven
``mvn clean package``

Это создаст файл my-market-app-0.0.1-SNAPSHOT.jar в папке target.
#### 2. Запуск приложения.
``java -jar my-market-app-0.0.1-SNAPSHOT.jar``

### Запустить приложение с помощью Docker
#### 1. Создайте образ
``docker build -t my-market-app .``
#### 2. Запустите контейнер
``docker run -d -p 8080:8080 --name my-market-app-container my-java-app``
Замените порты и имя контейнера по необходимости.

### Запустить приложение с помощью Docker Compose
Выполните команду
``docker-compose up --build``
